Teoria · nvidia-smi

2.Queries úteis e campos

# Query estruturado — ideal para scripts
nvidia-smi --query-gpu=index,name,temperature.gpu,\
utilization.gpu,utilization.memory,memory.used,\
memory.total,power.draw,power.limit,\
clocks.current.graphics,clocks.current.memory,fan.speed \
--format=csv,noheader,nounits

# Saída exemplo (GPU 0 — Tesla T4):
0, Tesla T4, 52, 87, 45, 3842, 15360, 48.2, 70.0, ...

# Campos disponíveis completos
nvidia-smi --query-gpu=help | head -60

# Monitoramento contínuo a cada 2 s
nvidia-smi dmon -s pucvmet -d 2

csv,noheader,nounits remove cabeçalho e unidades — perfeito para juntar com timestamp e gravar no CSV.

🌡️ Temperatura e energia

  • temperature.gpu — °C atual
  • power.draw — watts consumidos
  • power.limit — limite configurado

📈 Utilização e memória

  • utilization.gpu — % uso dos SMs
  • memory.used / memory.total — VRAM
Demo · Coleta e alerta

3.monitor_gpu.sh e alerta_gpu.sh

Coleta em CSV

#!/usr/bin/env bash
set -euo pipefail

INTERVALO="${1:-5}"
SAIDA="gpu_log_$(date +%Y%m%d_%H%M%S).csv"
AMOSTRAS=$(( ${3:-3600} / ${1:-5} ))

echo "timestamp,gpu_index,temp_c,util_gpu_pct,..." > "$SAIDA"
while [ "$AMOSTRA" -lt "$AMOSTRAS" ]; do
    TS=$(date +"%Y-%m-%d %H:%M:%S")
    nvidia-smi --query-gpu=index,name,temperature.gpu,\
utilization.gpu,memory.used,power.draw \
        --format=csv,noheader,nounits | while read -r l; do
        echo "$TS,$l" >> "$SAIDA"
    done
    AMOSTRA=$(( AMOSTRA + 1 ))
    sleep "$INTERVALO"
done

set -euo pipefail aborta em erro, variável vazia ou falha de pipe.

Alerta por limites

#!/usr/bin/env bash
LIMITE_TEMP="${1:-80}"
SLACK="${SLACK_WEBHOOK_URL:-}"

alerta() {
    echo "[$(date)] ALERTA: $1" | tee -a "$LOG"
    [ -n "$SLACK" ] && curl -s -X POST "$SLACK" \
        -H "Content-Type: application/json" \
        -d "{\"text\": \"GPU Alert: $1\"}"
}

while IFS=", " read -r idx nome temp util; do
    [ "$temp" -ge "$LIMITE_TEMP" ] && alerta "GPU $idx: ${temp}C"
done < <(nvidia-smi --query-gpu=index,name,\
temperature.gpu,utilization.gpu --format=csv,noheader,nounits)

Notifica por Slack (webhook) ou e-mail e registra em log. Thresholds configuráveis por argumento.

gnuplot <<'EOF'
set terminal png size 1400,900 enhanced
set output "gpu_dashboard.png"
set multiplot layout 2,2 title "GPU Monitoring Dashboard"
set datafile separator ","
set xdata time
set timefmt "%Y-%m-%d %H:%M:%S"
set format x "%H:%M"

plot "gpu_log.csv" using 1:4 with lines lw 2 title "GPU 0", \
     80 with lines dt 2 title "Limite 80C"          # temperatura
plot "gpu_log.csv" using 1:5 with lines title "GPU util", \
     "gpu_log.csv" using 1:6 with lines title "Mem util"   # utilização
unset multiplot
EOF

Coluna 1 = timestamp; eixo X em time. Alternativa em Python: pandas + matplotlib (usada no notebook do Colab).

import csv, os
from google.oauth2 import service_account
from googleapiclient.discovery import build

creds = service_account.Credentials.from_service_account_file(
    os.environ["GOOGLE_CREDS"],
    scopes=[".../auth/spreadsheets"])
service = build("sheets", "v4", credentials=creds)

with open("gpu_log.csv") as f:
    reader = csv.reader(f); next(reader)   # pula cabeçalho
    linhas = list(reader)

service.spreadsheets().values().append(
    spreadsheetId=os.environ["SHEETS_ID"],
    range="GPU_Logs!A:M",
    valueInputOption="USER_ENTERED",
    body={"values": linhas}).execute()

7.Debate — grupos de 3 a 4

1

O script coleta no mesmo servidor. Se o disco encher, o monitoramento para. Como tornar o sistema mais robusto e independente do job de treinamento?

2

cron e systemd são de servidor único. Para um cluster com 50 nós GPU, qual seria a arquitetura? Pesquise Prometheus, Grafana e DCGM.

3

O alerta está em 80 °C, mas a GPU aguenta 95 °C. Qual o limiar ideal? Que outros indicadores (fan.speed, power throttle) deveriam acionar alertas?

4

Google Sheets tem quota e latência. Em produção, o que substituiria essa integração? Compare com InfluxDB + Grafana.
