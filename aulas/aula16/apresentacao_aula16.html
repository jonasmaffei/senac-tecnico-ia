Versionamento

1.GitHub: A Rede de Segurança da IA

Ao usar agentes de IA que editam arquivos automaticamente, o GitHub/Git é a sua proteção contra erros e perda de código.

📜 Histórico Infalível

Cada alteração aceita vira um commit. Se a IA gerar um bug, basta dar git reset ou restaurar o estado anterior.

🔍 Transparência em Diffs

Com git diff ou o comando /diff no agente, você revisa linha por linha antes de aprovar.

☁️ Nuvem e Colaboração

Com git push, seu projeto fica seguro no GitHub, acessível e pronto para trabalho em equipe via Pull Requests.

Teoria · Contexto

2.O que é Contexto e Janela de Contexto?

O contexto é a quantidade total de dados que a IA consegue processar simultaneamente em sua "memória de trabalho".

Componentes do Contexto

  • Instrução do Usuário: O prompt enviado no terminal
  • Diretrizes do Projeto: O arquivo AGENTS.md
  • Arquivos Lidos: Código lido via ferramentas (tools)
  • Histórico da Conversa: Diffs e respostas anteriores

⚠️ Degradação de Contexto (Context Rot)

Contexto demais polui a memória da IA. Informações irrelevantes fazem o agente esquecer regras ou hallucinar. Mantenha o contexto limpo!

Teoria · Diretrizes

3.AGENTS.md: A Memória Persistente do Projeto

O AGENTS.md é um arquivo markdown na raiz do repositório lido **automaticamente** por agentes de IA (`agy`, Claude Code, Cursor).

O que colocar no AGENTS.md

  • Objetivo & Arquitetura: O que o projeto faz e sua estrutura
  • Convenções de Código: Idioma, tratamento de erros, estilos
  • Comandos de Execução: Como rodar o servidor e testes
💡 Em vez de repetir instruções a cada prompt, você escreve o AGENTS.md uma vez. Toda IA que abrir o repositório seguirá as mesmas regras.
Teoria · Harness

4.O Harness e o Loop Agêntico

O Harness conecta o modelo de IA ao seu computador: gerencia o loop, executa comandos e lê arquivos.

Prática · Laboratório

5.Prática: Monitoramento Web em Python

Criaremos uma aplicação web de monitoramento de sistema (CPU, RAM, Disco) com Flask + psutil guiados pelo AGENTS.md.

Comando no agy

# Dentro de laboratorio_monitoramento/ agy # Prompt no agente: "Leia o arquivo AGENTS.md desta pasta e crie a aplicação de monitoramento web em Python."

Componentes a Gerar

  • app.py — Servidor Flask e API JSON
  • coletor.py — Leitura de hardware com psutil
  • templates/index.html — Dashboard Dark Mode
  • iniciar.bat — Script de execução no Windows

Síntese

O que levar desta aula

  • GitHub: Sempre salvar o progresso com git add, commit e push.
  • Contexto: Informação enxuta gera respostas melhores da IA.
  • AGENTS.md: Defina regras estáticas do projeto para qualquer agente seguir.
  • Verificação: Use /diff antes de aprovar código gerado por IA.
