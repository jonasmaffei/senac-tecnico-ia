# 📝 Atividade: Aula 20 — Definição do Projeto Final

## 🎯 Situação

A empresa organizou um **hackathon de 4 semanas**: cada time deve criar uma solução de IA
acelerada por GPU para um problema real. Esta aula é o planejamento.

---

## 🚀 Roteiro

1. **Escolha o domínio** (visão, PNL ou séries temporais) e um **problema real**.
2. **Defina o dataset** e o **modelo base** (pré-treinado).
3. Rode o exemplo e ajuste para o seu projeto:
   ```bash
   cd aulas/bloco4/aula20/scripts
   python projeto_exemplo.py
   ```
4. Preencha o **checklist de prontidão** (todos os itens).

---

## 💬 Discussão em grupo (10 min)

1. Qual problema vocês escolheram? Como a GPU acelera a solução?
2. O dataset tem desafios (desbalanceamento, ruído)? Como tratar?
3. Qual será o baseline mais simples? Qual a métrica principal?

---

## 📚 Trilha de pesquisa (alternativa sem código)

Se o seu projeto for de **pesquisa** (como o PI), nesta etapa você define o **problema real**,
a **pergunta central** e o **roteiro de pesquisa** (fontes e alternativas de arquitetura).
Veja os exemplos 4–6 em [`projetos-exemplo/`](../projetos-exemplo/README.md).


## 📌 Tarefa de casa (para a Aula 21)

1. Completar o checklist e criar o **repositório GitHub**.
2. Testar o carregamento do dataset.
3. Implementar o **baseline** e medir a métrica principal.
