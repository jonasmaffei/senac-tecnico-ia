# 📝 Atividade: Aula 23 — Apresentação e Análise dos Projetos

## 🎯 Situação

O treino acabou e os resultados estão prontos. Chegou a hora de **apresentar** para a banca.

---

## 🚀 Roteiro

1. Gere o relatório final:
   ```bash
   cd aulas/bloco4/aula23/scripts
   python relatorio_final.py
   ```
2. Substitua os dados de exemplo pelos **reais** do seu projeto.
3. Monte o **pitch de 5 min**:
   - Problema → Solução → Demo → Resultados → Lições + PI.
4. Treine a apresentação cronometrando o tempo.

---

## 💬 Discussão em grupo (10 min)

1. O ganho de velocidade veio de qual técnica?
2. O monitor detectou algum evento real?
3. O gráfico de val/loss mostra overfitting ou underfitting?
