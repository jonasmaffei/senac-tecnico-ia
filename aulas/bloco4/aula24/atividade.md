# 📝 Atividade: Aula 24 — Conexão com o Projeto Integrador

## 🎯 Situação

A UC chegou ao fim. Agora é hora de ligar o que aprendemos ao **Projeto Integrador** do curso.

---

## 🚀 Roteiro

1. Rode o mapeamento no repositório do seu PI:
   ```bash
   cd aulas/bloco4/aula24/scripts
   python mapear_conexoes_pi.py /caminho/do/pi
   ```
2. Anote os pontos onde a GPU pode acelerar.
3. Veja o **plano de ação** do seu domínio (visão, PNL ou séries temporais).

---

## 💬 Discussão em grupo (10 min)

Cada time apresenta **3 conexões** GPU ↔ PI (2 min):

1. Qual componente do PI mais se beneficia de GPU?
2. O PI tem código numpy/sklearn/torch em CPU que poderia ir para a GPU?
3. Como o monitor da Aula 22 ajudaria o PI?

---

## 📚 Trilha de pesquisa (alternativa sem código)

As conexões GPU ↔ PI valem para as duas trilhas: indique onde a aceleração ajudaria o PI e
justifique com base na sua pesquisa.
